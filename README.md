# 산업연관 LAB

- **웹앱 / 과제 제출 주소:** https://513e.github.io/io-lab/
- **GitHub 저장소:** https://github.com/513E/io-lab
- **게시 방식:** Public · main · /(root) · Deploy from a branch

산업연관표·투입산출표를 불러와 산업 구조와 최종수요 변화의 파급효과를 분석하는 교육용 웹앱입니다. 특정 연도나 분류에 고정되지 않습니다. 한국은행 2023년 네 분류는 사용법을 익히기 위한 예시 자료입니다.

## 1. 내 자료 분석

1. **내 자료 불러오기**에서 XLSX 또는 UTF-8 CSV를 선택합니다. 파일은 30MB 이하이며 브라우저 내부에서 처리됩니다.
2. 한국은행 총거래표·국산거래표·수입거래표 형식은 헤더 위치, 산업 코드, 총산출·부가가치 행, 연도·단위를 찾아 자동 연결합니다. 시트명 또는 구조가 다른 파일은 직접 설정합니다. 자동 인식 후에도 자료 설정에서 내용을 확인·수정할 수 있습니다.
3. **자료 구조 설정**에서 분석 시트, 거래금액/투입계수 구분, 총거래/국산 기준, 첫 거래값 셀, 산업 수를 지정합니다. 산업 수는 1~600개입니다.
4. 산업 코드·이름의 첫 셀을 지정하면 아래 방향으로 읽습니다. 생략하면 순번·코드를 사용합니다. 거래 블록의 행·열 산업 순서는 같아야 합니다.
5. 거래금액표에는 총산출 벡터가 필수입니다. 총산출의 첫 셀과 읽는 방향(오른쪽 또는 아래)을 지정합니다. 투입계수표는 총산출 없이도 계수와 시나리오를 분석할 수 있습니다.
6. 부가가치, 국산·수입 거래표, 기준 최종수요는 선택적으로 연결합니다. 부가가치 입력은 거래금액표에서 금액, 투입계수표에서 계수입니다. 추가 시트는 주표와 동일한 산업 순서·수·단위·금액/계수 유형이어야 합니다.
7. 연도, 기준가격, 출처와 금액 단위를 확인하고 **이 설정으로 분석하기**를 누릅니다. 연도 미상은 비워 두세요. 단위를 모르면 먼저 원자료 설명을 확인하세요.

인식되지 않은 파일도 원자료 탐색에서 모든 시트를 행·열 좌표로 볼 수 있습니다. 분석에 필요한 범위를 지정하기 전에는 파급효과 계산이 활성화되지 않습니다. 수식 셀은 Excel 등에서 계산 후 저장된 수치가 필요합니다. 거래 블록의 빈 셀은 자동으로 0으로 간주하지 않습니다.

**지원 모형의 범위:** 산업×산업 또는 상품×상품의 대칭 정방형 투입산출표입니다. 행과 열의 분류가 다른 공급·사용표는 이 앱에서 직접 투입산출 모형으로 계산할 수 없으며, 적절한 가정으로 대칭표를 먼저 작성해야 합니다. 모든 기관의 복잡한 Excel 배치를 자동으로 인식한다는 의미는 아닙니다.

### 입력 양식

`data/io-template.xlsx`는 교육용 가상 3산업 표이며 실제 통계가 아닙니다. 값을 내 자료로 바꿔 사용할 수 있습니다. 기본 설정은 첫 거래값 C2, 산업 수 3, 산업코드 A2, 산업명 B2, 총산출 F2 아래로, 부가가치 G2 아래로입니다. H2 아래로를 기준 최종수요로 지정할 수도 있습니다. 연도·출처·단위·총거래/국산 구분은 본인의 자료에 맞게 지정하세요.

`code,name,<산업코드들>,output,value_added` 형식의 첫 행은 범위를 제안합니다. 적용 전에 자료 기준과 단위를 직접 확인해야 합니다. 부가가치 자료가 없다면 해당 설정은 비워 두세요.

## 2. 유지된 분석 기능

- **산업 대시보드:** 총산출·부가가치·수입중간투입률, 산업명·코드 검색, 지표별 순위, 상위 중간투입·배분 연결. 자료가 없는 지표는 0 대신 ‘자료 없음’ 또는 ‘—’으로 표시합니다.
- **원자료 탐색:** 모든 시트의 행·열 선택, 항목 검색, 조회 결과 CSV. 인식된 통계표는 코드와 산업명을, 일반 표는 Excel 행·열 좌표와 셀값을 사용합니다.
- **파급효과 실험실:** 여러 산업의 수요 증가·감소, 금액 또는 최종수요 대비 변화율, 최초 수요와 추가 파급분, 산업별 전체 결과, 시나리오 비교, CSV 저장.
- **분석 가이드:** 방법·단위·해석 범위·출처·현재 자료의 검증 결과.

새 자료를 불러오거나 설정을 적용하면 수요 시나리오·심화 결과는 초기화됩니다. 분류 비교를 위해 저장한 A·B는 자료 전환 중에도 유지되며 새로고침하면 지워집니다. 모든 결과와 저장값은 현재 브라우저 메모리에만 유지됩니다. 원자료를 서버로 전송하거나 저장하지 않습니다. 새로고침 후에는 다시 파일을 열어야 합니다.

변화율 입력은 기준 최종수요를 연결했을 때만 사용할 수 있습니다. 한국은행 국산거래표에서는 수출·소비·고정자본형성·최종수요계를 자동 탐색합니다. 다른 표는 지정한 최종수요 벡터를 사용합니다. 기준액은 양수여야 하며 감소율은 -100% 이상입니다. 총산출이 제공된 경우 감소 후 생산액이 음수가 되는 입력은 거부합니다.

## 3. 단위와 출처

계산 내부 금액은 **업로드 원자료 단위**를 유지합니다. 원·천원·백만원·억원·십억원·조원은 표시 단위를 환산할 수 있습니다. `million USD` 등 다른 단위는 원래 단위 그대로 표시하며 환율 변환을 하지 않습니다. 계수(배)와 비율(%)은 금액 환산 대상이 아닙니다. 일반 원자료 격자는 셀의 단위를 단정하지 않고 ‘원자료값’으로 보여 줍니다.

CSV에는 실제 파일명·출처·연도·분류·산업 수·기준가격·원자료 단위·모형 기준을 기록합니다. 금액은 원자료 단위로 내보내며 없는 수입·부가가치 결과는 빈 값으로 남깁니다. 인식된 표라도 시트별 단위가 다르면 금액 환산 대상에서 제외합니다.

## 4. 계산 방법과 해석

행 i는 공급 산업, 열 j는 구매 산업입니다. x는 총산출, Z는 중간거래, v는 부가가치계수입니다.

```text
A = Z diag(x)^(-1)
L = (I - A)^(-1)
Δx = L Δf
추가 파급분 = (L - I) Δf
수입 자료 연결 시: Am = Zm diag(x)^(-1), Δm = Am L Δf
부가가치 연결 시: v = VA / x, Δv = diag(v) L Δf
```

- 국산거래표가 있으면 국산 A를 사용하여 국내 생산물 수요에 대한 파급효과를 계산합니다.
- 총거래표에 국산 또는 수입을 연결하면 차감으로 나머지를 구합니다. 세 표가 모두 있으면 `총거래 = 국산 + 수입`을 확인합니다.
- 국산·수입을 구분하지 못하는 총거래표는 **총거래 기반 산출 요구량**을 계산합니다. 이를 국내 생산유발액으로 해석할 수 없습니다. 화면과 CSV에 모형 기준을 표시합니다.
- 유발계수 시트가 없어도 거래표와 총산출 또는 직접 입력한 투입계수로 L을 계산합니다. 제공된 유발계수 시트는 원자료에서 탐색하고 계산 검증 패널에서 재계산값과 대조합니다.
- 총산출이 0이고 해당 중간투입 열과 부가가치도 0이면 투입계수를 0으로 처리하고 안내합니다. 총산출 0인데 투입이 존재하면 오류입니다.
- 역행렬 잔차 `max| (I−A)L−I | < 10^-8`과 수치 안정성을 확인합니다. 수입·부가가치 계수는 해당 자료가 있을 때만 계산합니다.
- 영향력계수 = L 열합 / 열합 평균. 감응도계수 = L 행합 / 행합 평균. 분류 내부의 상대 지수이며 투자수익성·정책 우선순위가 아닙니다.

기준자료의 가격·기술·투입비율이 고정된 선형 모형입니다. 가격 조정, 공급능력 제약, 기술 대체, 가계소득에 따른 추가 소비는 포함하지 않습니다. 결과는 조건부 추정이며 미래의 확정적 예측이 아닙니다. 생산유발액은 중간재의 반복 생산을 포함하므로 부가가치나 GDP 증가와 동일하지 않습니다. 최초 수요는 이미 총효과에 포함됩니다. 증가·감소가 섞이거나 감소만 있는 시나리오에는 순변화 대비 배율을 표시하지 않습니다.

서로 다른 연도·가격·분류·단위의 결과를 직접 비교하거나 계수를 임의 합산·평균하면 안 됩니다. 노동유발 분석은 현재 산업코드에 정확히 맞는 노동계수를 연결한 경우에만 제공합니다.

## 6. 실행과 GitHub Pages 제출

1. 배포 ZIP의 내용물을 GitHub 저장소 최상위에 올립니다. ZIP 자체나 감싼 폴더만 올리지 않습니다.
2. `index.html`, `style.css`, `app.js`, `advanced.js`, `comparison.js`, `statistics.js`, `statistics.css`, `stats-math.js`, `stats-worker.js`, `worker.js`, `model.py`, `advanced.py`, `course.py`, `course.js`, `course.css`, `.nojekyll`, `README.md`, `data/`가 같은 최상위 위치에 있어야 합니다.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save를 선택합니다.
4. 실제 Pages 주소에서 파일 로딩·검색·계산·CSV 저장을 확인합니다. 과제의 제출 주소는 본인의 GitHub Pages 주소입니다.

별도 API 키나 Python 서버는 필요하지 않습니다. 브라우저 Web Worker에서 Pyodide 0.27.7, NumPy, openpyxl 3.1.5를 사용합니다. 최초 실행에는 외부 패키지 다운로드를 위한 인터넷 연결이 필요합니다. 로컬 점검은 정적 HTTP 서버를 사용하세요. `file://` 직접 열기는 지원하지 않습니다.

### 다른 연도·기관의 보조자료 연결

심화 분석 하단 **추가 자료 연결**에서 현재 파일의 시트·첫 수치 셀·방향을 지정합니다. 각 벡터는 현재 산업 수만큼, 유발계수는 N×N 정방형으로 읽습니다. **산업 순서·연도·통계 범위·단위를 먼저 맞춰야 합니다.** 가격 항목은 비용 금액 또는 산출 1단위당 계수로 지정합니다. 국산/수입 최종수요는 소비·고정투자·재고/귀중품·수출별로 연결할 수 있습니다. 없는 값은 0으로 채우지 않습니다.

노동계수는 별도의 UTF-8 CSV로도 연결할 수 있습니다:

```csv
code,jobs,employees,jobsMultiplier,employeesMultiplier
A,18.0,2.0,23.0,4.0
B,4.0,3.0,8.0,6.0
```

위 수치는 형식 설명용 가상값입니다. `jobs`=취업계수, `employees`=고용계수, `jobsMultiplier`/`employeesMultiplier`=공표 유발계수입니다. 모든 현재 산업코드가 정확히 한 번씩 있어야 합니다. 사용하지 않는 열은 삭제하거나 열 전체를 비우세요. 일부 산업에만 빈 값이 있는 계수 열은 거부합니다. 새 CSV는 이전 노동계수를 교체하며, 검증에 실패하면 이전 연결을 유지합니다. 원화 자료는 `명/10억원`, 외화 등은 `명/원자료 1단위`를 선택합니다. 잘못된 연도·단위의 계수를 가져오지 않도록 원자료를 확인하세요.

예시 보조자료는 통계표 18–20번의 2023년 대분류 33부문에 한해서 연결됩니다. 세부 분류에 33부문 계수를 복제하지 않습니다. 다른 분류·연도는 해당하는 노동계수를 연결하세요.

### 심화 공식과 해석

- **가격 / 비용 모드:** Δp = Lᵀ Δc. Δc는 각 비용항목의 산출 대비 계수×변화율 합입니다. 수입가격·투입량·노동생산성 고정, 비용 완전 전가를 가정합니다. 순생산세 변화율은 세율의 %p가 아닙니다. 음수인 순생산세·영업잉여에 양의 변화율을 적용하면 비용이 감소할 수 있습니다. 산출액 가중 평균은 CPI가 아닙니다.
- **Ghosh:** B = diag(x)⁻¹ Zᵈ, G=(I−B)⁻¹, Δx=GᵀΔq. q=x−Zᵈ의 열합은 부가가치+수입중간투입입니다. 고정 배분비율의 기초투입 변화 실험이며 물리적 공급능력 차질 예측으로 읽지 않습니다. 이 해석 문제는 Dietzenbacher (1997), https://onlinelibrary.wiley.com/doi/abs/10.1111/0022-4146.00073 을 참고합니다.
- **최종수요:** 국산 항목 f에 대해 생산 Lf, 부가가치 Vf, 수입 Mf+수입 최종수요를 사용합니다. 수입 최종수요가 연결되지 않으면 수입 중간재만 계산하고 표시합니다. 재고증감의 기여는 음수일 수 있으며 순합계가 0이면 기여율을 표시하지 않습니다. 보고서의 투자는 고정투자+재고/귀중품입니다.
- **노동:** 원자료가 백만원이고 e가 명/10억원이면 산업별 노동투입 = diag(e)LΔf/1,000. 직접투입 = eᵀΔf/1,000. 공표 유발계수 h는 총인원 hᵀΔf/1,000만 제공합니다. 공표 계수의 원래 계산·집계 방식에 따라 재계산한 33부문 eᵀL과 차이가 날 수 있으므로 오류 판정에서 제외합니다. 취업은 자영업자·무급가족종사자를 포함하며 고용은 임금근로자입니다. 모두 조건부 연간 노동투입 규모로 영구 신규채용 확정치가 아닙니다.
- **분류 비교:** 두 자료의 연도·가격·단위·모형이 같아야 합니다. A의 산업을 선택하고 동일한 수요 1단위를 B의 해당 세부 산업에 배분한 가중 승수와 비교합니다. 차이는 집계 수준과 수요 구성의 영향을 함께 담으므로 순수 집계편의만을 식별하는 추정치는 아닙니다. 메타데이터 미지정은 확인 체크가 필요합니다. 연결표는 `coarse_code,fine_code` 두 열로 모든 세부 산업을 한 번씩 연결합니다. 세부 총산출이 모두 0이면 산출 비중을 사용할 수 없습니다.

| 구조 지표 | 정의 |
|---|---|
| 수출률 | 수출액 / 총산출 ×100 |
| 수입률 | 수입계(수입생산물세 포함) / 총공급계 ×100 |
| 부가가치율 | 부가가치 / 총투입 ×100 |
| 중간투입률 | 국산+수입 중간투입 / 총투입 ×100 |
| 국산화율 | 국산 중간투입 / 전체 중간투입 ×100 |
| 자기부문 중간투입 비중 | 자기부문 중간투입 / 전체 중간투입 ×100, 앱에서 정의한 보조 지표 |

### 검증 자료의 범위

2023년 4개 분류 각각에서 역행렬·제공 유발계수·최종수요 유발액 16개 항목과 공표 통계 11개 항목을 대조합니다. 행렬은 최대 절대 오차 10⁻⁸, 금액표는 원자료 반올림과 규모, 공표 통계는 공표 자리수를 고려한 허용오차를 보여 줍니다. 보고서의 전산업 생산·부가가치·수입 유발계수는 **국산 최종수요 가중 평균**으로 계산합니다. 단순 산업평균이 아닙니다.

`advanced-verification.json`에 4분류 검증 결과와 작은 비대칭 가상표를 사용한 전치·행/열 분모·단위·누락자료·음수충격 점검 결과를 기록했습니다. 이 배포 저장소에는 실행 파일과 검증 결과 요약을 포함합니다. 앱의 **분류 비교·검증 → 계산 검증**에서 현재 자료와 제공된 계수·공표 통계를 직접 대조하고 CSV로 저장할 수 있습니다. `data/reference-2023.json`의 값은 현재 업로드에 임의 적용하지 않으며 연도·코드·총산출이 맞는 예시에만 연결합니다.


## 10. 통계 탐색 (2026-11-14 추가)

**통계 탐색** 메뉴에서 현재 업로드 또는 예시 자료의 산업을 동일 가중치로 비교합니다. 특정 연도나 분류에 고정하지 않습니다. 산업 검색은 선택 목록만 좁히며 분석 대상 전체를 바꾸지 않습니다. 산업 선택은 세 화면에 연동되고, 대시보드의 연결 구조 또는 수요 실험으로 이동할 수 있습니다.

| 화면 | 기능 | 방법·단위 |
|---|---|---|
| 분포와 위치 | 히스토그램, 상자그림, 평균·중앙값·표준편차, 선택 산업의 순위·백분위 | 계수는 배, 구조 비율은 %, 상대지수는 지수, 총산출은 원자료 금액 단위 |

### 분포와 상관계수

- 결측·비유한값은 0으로 대체하지 않습니다. 유효 산업 수와 제외 수를 표시합니다. 총산출은 상단의 표시 단위 변경과 무관하게 **원자료 금액 단위**를 사용하며 축·CSV에 명시합니다.
- 기술통계 표준편차의 분모는 n입니다. 사분위수는 정렬 후 `(n−1)p` 위치를 선형 보간하는 Type 7 방식입니다. 상자그림 수염은 Q1−1.5IQR부터 Q3+1.5IQR까지 범위 안의 가장 바깥 관측값이며, 그 밖의 점을 오류라고 단정하지 않습니다.
- 내림차순 순위는 `1 + 자신보다 큰 값의 수`, 백분위 위치는 `100 × (자신보다 작은 값의 수 + 동점 수/2) / n`입니다. 동점을 반영한 상대적 위치이며 정책 우선순위·우수성 지표가 아닙니다.
- 히스토그램 자동 구간 수는 `ceil(sqrt(n))`을 3~24개로 제한합니다. 상수 지표는 1개 구간으로 표시합니다.
- 피어슨은 원래 지표의 선형 상관, 스피어만은 평균순위를 사용한 순위 상관입니다. 유효 쌍 2개 미만 또는 상수 지표의 상관계수는 표시하지 않습니다. 산점도는 스피어만 모드에서도 원래 지표의 값을 표시합니다.
- 점 크기를 바꿔도 상관계수는 동일 가중치입니다. 총산출 비례 면적은 최소 가시 반지름 2px를 적용하며, 0·결측 총산출은 고정 크기로 표시합니다.
- 부가가치율과 중간투입률의 회계적 보완관계, 생산유발계수와 영향력계수의 정의상 관계를 별도로 안내합니다. p값·유의성 검정·인과효과는 제공하지 않습니다.

### PCA와 군집

1. 선택한 모든 지표가 있는 산업을 사용하고, 제외된 산업 코드·이름을 공개합니다. 산업이 3개 미만이면 실행하지 않습니다.
2. 각 지표에서 평균을 빼고 **표본 표준편차(분모 n−1)**로 나눕니다. 상수·수치적으로 매우 작은 변동의 지표, 완전 선형 중복 지표는 사유와 함께 제외합니다. 남은 지표가 2개 미만이면 다른 지표 선택을 안내합니다.
3. 표준화 자료의 상관행렬을 대칭 Jacobi 고유분해로 계산합니다. 지도에는 PC1·PC2를, 각 축에는 설명분산 비율을 표시합니다. 적재량은 고유벡터×고유값의 제곱근으로, 원 지표와 주성분의 상관입니다. 고유벡터 부호는 가장 큰 절댓값의 성분이 양수가 되도록 고정합니다.
4. 군집은 **PCA 지도상의 거리만으로 계산하지 않고 모든 채택된 표준화 지표에서** k-means++로 구합니다. 군집 수는 2~6이며 산업 수보다 작고 서로 다른 관측값 수 이하여야 합니다. 시드 20261114, 8회 초기화, 각 최대 150회 갱신 중 군집 내 제곱거리 합이 가장 작은 결과를 사용합니다. 군집 번호는 PC1 평균 순으로 정렬합니다.
5. 실루엣은 동일한 전체 표준화 공간의 유클리드 거리로 계산하고, 단일 산업 군집은 0으로 처리합니다. 군집 수를 자동으로 최적화하지 않습니다. 군집 평균 막대는 분석 대상 전체 평균 대비 표준편차 단위입니다.

표의 산업은 독립적으로 무작위 추출된 표본이 아닙니다. 이 기능은 현재 산업구조를 요약하는 탐색적 분석이며 미래 예측·정책 효과 추정이 아닙니다. 2차원 설명분산이 낮으면 지도에서 가까운 산업이 전체 지표 공간에서도 반드시 가깝지는 않습니다. 분류·연도별로 따로 산출한 PCA 축과 군집 번호는 직접 대응하지 않습니다. 군집 수와 선택 지표에 따라 결과가 달라지고, 경제적 유형명은 자동으로 붙이지 않습니다.

### 저장과 재현

각 화면에서 CSV와 독립형 SVG를 내려받을 수 있습니다. CSV에는 출처·연도·분류·단위·방법·선택 조건을, SVG에는 시각적 자료 표기와 상세 조건 메타데이터를 포함합니다. PCA CSV에는 좌표·군집·표준화 기준·적재량·제외 대상도 포함합니다. 새 자료를 불러오거나 추가 자료를 연결하면 이전 통계 결과를 초기화하며, PCA의 지표 또는 군집 수를 바꾸면 재계산 전까지 이전 결과와 내보내기를 비활성화합니다. 통계 계산도 브라우저 내부에서 처리하며 PCA는 별도의 Web Worker에서 실행합니다.

`node statistics-check.cjs`로 사분위수·결측 처리·동점 순위·상수 상관·고유분해·군집 재현성·예외 처리의 7개 검증 묶음을 실행할 수 있습니다. 네 원본 분류를 이용한 추가 검증과 NumPy 대조는 `statistics-verification.json`에 기록했습니다. 기본 6개 지표를 모두 가진 산업은 대분류 33, 중분류 83, 소분류 164, 기본부문 374개입니다. 제외된 산업은 원자료의 분모 0 등으로 일부 비율이 계산되지 않는 경우이며 0으로 채우지 않았습니다.

## 11. 표 읽기·경제구조·가격 실험 확장

### 표 읽기·학습

자료를 불러온 뒤 **표 읽기·학습**에서 공급 산업(행)과 생산·수요 대상 산업(열)을 선택합니다. 네 단계는 자유롭게 이동할 수 있습니다.

1. **거래 읽기:** 선택한 교차 셀 주변의 실제 거래값을 표시합니다. 셀을 누르면 공급·사용 산업이 함께 바뀝니다. 국산·수입이 연결된 경우 같은 위치의 `총거래 = 국산 + 수입`을 표시합니다.
2. **합계·구조:** 대상 산업의 `총투입=총산출`, `중간투입+부가가치`, `총수요=총공급`, `중간수요+최종수요`와 합계 차이를 표시합니다. 투입률의 분모(총투입)와 수요율의 분모(총수요)를 구분합니다.
3. **계수 해석:** 직접 투입계수의 거래액/총산출, 해당 유발계수 셀, 전 산업 열합의 의미를 구분합니다. 계수는 배이며 금액 단위 환산의 영향을 받지 않습니다.
4. **수요 실험:** 선택 산업의 최종수요 변화액을 상단 표시 단위로 입력합니다. 최초 수요·추가 파급·총효과와 부가가치·수입 중간재 효과를 함께 설명합니다. 부가가치·수입을 생산유발액에 다시 더하지 않습니다.

행렬 편집, 파이썬 실행, 객관식 문제·정답·채점 기능은 포함하지 않습니다. 실제 자료의 의미와 결과 해석에 집중합니다. 거래금액이 없는 계수표는 해당 금액을 ‘자료 없음’으로 표시하며 계수와 수요 실험은 사용할 수 있습니다. 총거래 모형은 국내 생산효과가 아닌 수입 미분리 산출 요구량으로 표시합니다.

### 경제구조 비교

- 산업별 `총산출 / 전 산업 총산출`과 `부가가치 / 전 산업 부가가치`를 나란히 그립니다. 정렬·검색 및 비중 차이 절댓값 정렬을 제공합니다. 차이는 %p입니다. 검색해도 분모는 전체 산업 합계로 유지됩니다.
- 상세 카드에서 분자·분모 금액과 계산 비율을 확인합니다. 부가가치 비중과 부가가치율은 서로 다른 분모를 사용합니다.
- `중간수요율=총거래 행의 중간수요/총수요×100`, `최종수요율=총거래 최종수요/총수요×100`입니다. 총수요는 총공급계 또는 명시적으로 연결된 총산출+수입계입니다.
- 한국은행 총거래표의 9190열을 최종수요계로 연결합니다. 일반 자료는 **심화 분석 → 추가 자료 연결 → 총거래 최종수요계**에서 같은 산업 순서의 금액 벡터를 연결할 수 있습니다. 총공급계도 같은 곳에서 연결합니다. 국산·수입 최종수요의 네 항목이 모두 있으면 그 합을 사용할 수 있습니다.
- 최종수요를 `총공급−중간수요`로 추정해 채우지 않습니다. 결측 또는 분모 0은 계산 불가로 표시합니다. 음수 재고·조정항목은 유지하며 합계 차이를 별도로 보여 줍니다.
- CSV에는 검색한 산업의 원자료 단위 금액, 비율, 합계 차이, 분모 합계 및 연결 출처를 저장합니다.

### 가격 실험 4개 모드

| 모드 | 입력 | 모형과 가정 |
|---|---|---|
| 부가가치 비용 | 산업별 또는 전 산업 피용자보수·순생산세·영업잉여 변화율 | `Δp=LᵀΔc`. 수입가격·투입량·노동생산성 고정, 비용 완전 전가. |
| 수입 상품가격 | 특정 수입 상품/전체의 외화가격 변화율 + 공통 환율 변화율 | `Δp=LᵀAmᵀΔpm`. 선택 상품은 `(1+외화가격변화율)(1+환율변화율)−1`, 나머지 상품은 환율 변화만 적용. |
| 환율 | 국내통화/외화 환율 변화율 | 모든 수입 중간재에 동일하게 적용. 외화가격 고정, 국내통화 가치 하락이 양수. |
| 특정 국내 상품가격 | 고정할 한 상품의 가격 변화율 | 해당 부문 j를 외생화하고 나머지 E에 대해 `ΔpE=(I−AEEᵀ)⁻¹ AjEᵀΔpj`. 선택 상품 가격을 다시 증폭하지 않음. |

기준 가격지수는 1이며 변화율은 %입니다. 수입가격·환율 모드는 부가가치 단위비용과 투입계수를 고정하고 수입 중간재 가격을 완전 전가합니다. 환율 10%와 선택 상품의 외화가격 10% 상승은 해당 수입품의 국내통화 가격 21% 상승입니다. 환헤지·통화별 결제 비중·부분 전가·수출수요 반응·최종 수입재 소비자가격은 반영하지 않습니다.

국내 상품가격 모드는 다른 부문의 부가가치 단위비용과 수입가격을 고정합니다. 선택 상품의 표에는 ‘외생가격 고정’을 표시하며, 그 행의 최초 변화는 비용 충격이 아니라 입력한 가격입니다. 산출액 가중 평균에는 고정한 상품도 포함합니다. 산업별 변화율을 합산하지 않으며 가중 평균도 CPI나 GDP 디플레이터가 아닙니다. 서로 다른 실험은 인과효과 추정이 아니라 명시한 가정의 조건부 비교입니다.

현재 결과를 비교 기준으로 저장한 뒤 다른 입력으로 다시 계산하면 산업별 차이(%p)를 볼 수 있습니다. CSV에 모드·대상·입력·가정과 비교 기준을 기록합니다. 입력 변경 시 현재 결과를 지우고, 자료 변경 또는 보조자료 재연결 시 비교 기준도 지웁니다. 감소율 -100% 미만, 비유한 입력, 음수 가격을 만드는 시나리오는 거부합니다.

### 검증과 파일

`course.py`는 표 해석·경제구조 계산, `course.js`와 `course.css`는 학습·구조·확장 가격 화면을 담당합니다. 가격 계산은 `advanced.py`에 있습니다. `worker.js`가 모두 브라우저에서 로드합니다. 강의 PDF 원문과 개인 정보는 게시 파일에 추가하지 않습니다.

## 12. 총산출 변동요인 분해 (2026-11-18)

**총산출 변동분해** 메뉴는 두 시점의 산출액 차이를 국내최종수요·국산 수출·최종재 수입대체·중간재 수입대체·기술구조의 다섯 요인으로 분해합니다. 기존 심화 분석의 한 시점 최종수요 항목별 분해와 다릅니다.

1. 상단에서 기준시점 거래표를 열고 `현재 자료를 기준시점으로 저장`합니다.
2. 같은 산업분류의 다른 연도 자료를 열고 비교시점으로 저장합니다. 저장한 두 시점은 자료 전환 중 유지되고 새로고침하면 지워집니다.
3. 경상가격/공통 기준년 불변가격을 선택하고 동일 분류·가격 조건을 확인합니다. 불변가격은 기준연도를 입력합니다. 앱이 물가 조정을 수행하지 않습니다.
4. 분해 후 전산업 또는 산업별 폭포형 차트, 파셰·라스파이레스·두 방식 평균 비교표, 검색 가능한 산업별 기여액을 확인합니다. CSV에는 모든 산업·세 방식·두 출처·가격 조건과 회계 잔차를 기록합니다. 금액은 저장한 자료의 원래 단위로 표시합니다.

**가상 예제로 먼저 실습**은 3개 산업의 가상 2015·2020년 균형표를 생성합니다. 실제 연도별 통계가 아니며, 2023년 예시를 다른 연도의 실제 자료로 변형한 것이 아닙니다. 현재 불러온 자료를 교체하지 않습니다.

필수 자료는 국산·수입 중간거래, 총산출, 국산과 수입의 소비·고정투자·재고/귀중품, 국산 수출입니다. 한국은행 형식은 자동 연결하고 다른 형식은 기존 추가 자료 연결을 사용합니다. 산업 코드 집합·명칭·분류·단위·가격 평가기준을 검사하고 순서만 다르면 코드로 정렬합니다. 비교 연도는 기준 연도보다 뒤여야 합니다. 명목 자료의 기술구조 변화는 가격 변동을 포함하므로 순수 생산성 변화로 해석할 수 없습니다.

### 분해식

강의 제6장 총산출액 변동요인 분해의 Syrquin 방식과 같은 두 경로를 사용합니다. `⊙`, `⊘`는 원소별 연산입니다.

```
A = (Zd + Zm) diag(x)^(-1), Am = Zm diag(x)^(-1)
S = Am ⊘ A, M = 수입 국내최종수요 ⊘ F
L = [I − (1 − S) ⊙ A]^(-1)
x = L[(1 − M) ⊙ F + E]

파셰:
국내최종수요 = L1 [(1−M1) ⊙ ΔF]
수출 = L1 ΔE
최종재 수입대체 = −L1 [ΔM ⊙ F0]
중간재 수입대체 = −L1 [(ΔS ⊙ A0) x0]
기술구조 = L1 [((1−S1) ⊙ ΔA) x0]
```

라스파이레스는 L1/M1/S1을 L0/M0/S0으로, F0/A0/x0을 F1/A1/x1로 교체합니다. Δ는 비교−기준입니다. F는 국산+수입 국내최종수요이며 수출을 제외합니다. E는 국산 수출로, 재수출을 국내 생산으로 중복 계산하지 않습니다. 평균은 두 경로의 산술평균으로 유일한 분해값이나 인과효과를 뜻하지 않습니다.

한 시점에서 총투입계수 또는 국내최종수요가 0이면 해당 수입비율은 다른 시점의 비율을 적용합니다. 양 시점 모두 0이면 0입니다. 신규·소멸 거래의 비율을 식별할 수 없어 필요한 관례이며 적용 개수를 표시합니다. 분모 0인데 수입분자가 0이 아니거나 총산출 0인 투입 열에 거래가 있으면 거부합니다. 음수 재고는 그대로 사용합니다.

회계 불일치가 있는 자료는 `관측 산출 변화 − 다섯 기여액의 합`을 별도 회계 잔차로 표시하며 이를 경제적 요인으로 해석하지 않습니다. 기준·비교 시점의 산업별 수급 불일치 최댓값도 표시합니다. 기여율은 관측 변화액 대비 비율이며 변화가 0이면 표시하지 않습니다. 기여율은 음수 또는 100% 초과일 수 있습니다.

## 13. 지역경제 분석실 (2026-11-18)

**지역경제 분석실**은 지역×산업 국산 거래를 사용하여 산업 특화도(LQ), 지역 간 거래, 수요 변화의 지역내·타지역 파급효과, 부가가치 이입·이출을 분석합니다. 특정 연도나 2023년 자료에 한정하지 않습니다. 기존 전국표와 별도 상태를 유지하며 새로고침하면 초기화됩니다.

- **가상 지역경제 불러오기**: 실제 통계와 구분한 3지역×3산업 균형표로 즉시 실습합니다.
- **입력 양식**: `regional-template.xlsx`의 가상 숫자를 본인 자료로 교체합니다. `metadata`(연도·단위·가격·출처·지역 범위), `nodes`(고유 code·지역·공통 산업 코드/명칭·총산출), `transactions`(국산 중간거래)가 필수입니다. `value_added`, `imports`, `employment`는 선택 열입니다. 없으면 해당 열 전체를 비우며, 일부만 비우면 오류를 표시합니다. 수입은 해외 중간재 수입의 투입 열합, 취업은 기준 취업자수(명)입니다.
- **선택 final_demand 시트**: 공급 지역×산업 code 행, 국내 최종수요 목적지 지역 열, 해외 수출 exports 열입니다. 없는 경우 시트 전체를 삭제합니다. 지역별 최종수요와 부가가치가 모두 있어야 부가가치 이입·이출을 계산합니다.
- **현재 표 연결**: 상단에서 지역간 국산 거래표를 불러와 설정한 뒤, 현재 코드의 연결 CSV를 내려받아 `code,region,industry,name`을 채웁니다. 지역별로 동일한 산업분류가 필요합니다. 이 경로는 지역별 최종수요 목적지·취업 자료를 복사하지 않습니다.

일반 전국 산업표의 산업에 임의로 지역명을 붙여서는 지역간 효과를 식별할 수 없습니다. 일부 지역만 입력했다면 LQ의 참조범위도 입력된 지역 전체이고, 누락 지역 파급효과는 계산하지 못합니다. 2~30개 지역과 최대 600개 지역×산업 조합, 30MB 이하 XLSX를 지원합니다. 공통 산업이 실제 없는 지역은 확인된 0을 명시하고, 미관측 값을 0으로 대체하지 않습니다. 금액은 자료의 원래 단위로 계산합니다.

### 화면과 해석

LQ 열지도는 `지역내 산업 산출비중 / 전체 수록 지역의 해당 산업 산출비중`입니다. LQ>1은 상대적 특화이며 생산성이나 정책 우선순위가 아닙니다. 셀을 누르면 수요 실험의 대상 지역·산업을 선택합니다. 지역내 산업 비중과 해당 산업 중 지역 비중은 분모를 구분해 표시합니다.

지역 거래 행렬은 공급 지역을 행, 구매 지역을 열로 둡니다. 국산 중간거래만 또는 국산 중간거래+국내 최종수요를 선택할 수 있습니다. 해외 수출·수입은 포함하지 않습니다. 셀 선택 시 판매 비중과 조달 비중을 구분합니다.

수요 실험은 `A=Zd diag(x)^−1`, `L=(I−A)^−1`, `Δx=LΔf`를 사용합니다. 입력 지역은 **수요 대상 생산물의 생산지**이며 지출자의 거주지가 아닙니다. 전체 산업 선택 시 기준 산출 비중 또는 산출이 있는 산업에 균등 배분합니다. 지역내·타지역 생산, 부가가치, 수입 중간재, 취업 투입을 구분합니다. 지역내 생산은 역내 경로 `(I−Arr)^−1Δfr`와 다른 지역을 경유해 돌아온 환류로 나눕니다. 음수 충격도 지원하지만 기준 총산출보다 큰 감소는 거부합니다. 산출 0인 부문의 신규 생산은 기존 계수로 추정하지 않습니다.

부가가치 흐름은 `diag(v)LF`를 생산 지역별로 집계합니다. 강의 제7장의 정의에 따라 **이입=타지역 최종수요가 자기지역에서 유발한 부가가치**, **이출=자기지역 최종수요가 타지역에서 유발한 부가가치**입니다. 순이입은 이입−이출이고 자기지역과 해외 수출 효과는 제외합니다. 실제 소득 송금 또는 무역수지가 아닙니다.

고정 투입계수, 공급능력 제약·가격 반응·가계 재지출 미반영의 조건부 결과입니다. 취업은 고정 취업계수에 따른 필요 투입 인원이며 영구 신규채용이 아닙니다. 생산유발액에 부가가치나 수입을 다시 더하지 않습니다. 구조·교역 및 실험 CSV에 출처·연도·단위·범위·가정과 상세 결과를 기록합니다.

## 14. 과점시장 실험실 (2026-11-18)

**과점시장 실험실**은 강의 제1장의 선형수요·일정 한계비용 모형을 독립적으로 실습합니다. 상단 산업연관표에서 기업 수요·비용·시장점유율을 추정하지 않습니다. 자료 업로드나 Python 엔진 없이 바로 실행되며, 모든 숫자는 설정한 가상 조건의 임의 단위입니다. 행렬 편집·Python 실습·객관식 문제는 추가하지 않습니다.

1. 수요 `P=a−bQ`, 공통 한계비용 c, 기업 수 n, 기업당 진입비용 e를 입력하고 **시장 계산하기**를 누릅니다. a>c, b>0, 정수 n=1~100을 지원합니다. 가격은 금액/수량, 수량은 수량, 이윤·잉여는 금액 단위이며 상단 원자료 표시 단위와 독립입니다.
2. **동질재 모형 비교**에서 독점·균등 할당 담합·n기업 쿠르노·2기업 스타켈베르크·n기업 베르트랑·완전경쟁 기준을 비교합니다. 모형 선택 시 수요·비용 그래프와 가격·수량·이윤·소비자잉여 카드가 바뀝니다. 이윤 합계·소비자잉여·사중손실·HHI·러너지수를 표로 확인합니다. 쿠르노 결과를 저장해 입력 변경 전후를 비교할 수 있습니다.
3. **반응함수·선도자**에서 기업 2의 비용을 따로 입력합니다. 동시 수량 경쟁과 기업 1이 수량을 먼저 확약하는 결과를 비교하며, 슬라이더로 상대 수량에 대한 기업 1의 최적반응을 확인합니다. 생산량 0의 경계해를 처리합니다.
4. **제품 차별화**는 같은 선호에 기초한 쿠르노·베르트랑과 순차적 가격경쟁을 비교합니다. 대체 정도 ρ 슬라이더는 0~0.95입니다. ρ=0에서 독립적인 제품의 독점 결과가 일치하고, ρ>0에서 가격이 전략적 보완재임을 보여줍니다. 가격 반응함수는 두 수요가 비음수인 내부해 유효구간만 표시합니다.
5. **기업 수·진입**에서는 1~100기업의 가격·수량·집중도·이윤과 진입비 차감 후 후생을 비교합니다. 자유진입 및 사회적 최적 기업 수는 0기업도 포함한 정수로 별도 계산하므로 그래프 범위를 넘을 수 있습니다. e=0이면 유한한 균형 기업 수가 없다고 안내합니다.

### 모형과 해석

동질재 대칭 쿠르노: `q=(a−c)/[b(n+1)]`, `P=(a+nc)/(n+1)`, `π=(P−c)q`. 담합 총수량은 독점 수량 `(a−c)/(2b)`이고 n개 기업에 균등 배분합니다. 한 기업의 담합 이탈은 다른 기업의 할당량을 고정한 1회 최적반응이며 새로운 내시균형이 아닙니다.

동질재 베르트랑은 동일 비용·무제한 생산능력·동시 가격 결정·동가 균등 배분의 n≥2 모형입니다. 균형가격 c, 이윤 0이 됩니다. 1기업에는 제공하지 않습니다. 스타켈베르크는 기업 1 선도·기업 2 추종의 수량 모형으로 2기업 고정입니다. 따라서 n≠2에서 다른 모형과 비교하면 기업 수 차이도 함께 포함됩니다.

비대칭 두 기업 쿠르노는 `BR_i(q_j)=max[0,(a−c_i−bq_j)/(2b)]`의 교점이며, 내부해가 음수이면 비생산 경계해를 사용합니다. 수량 선도는 추종자의 반응함수를 대입한 선도자 이윤을 내부·비생산 구간 각각에서 최대화합니다. 높은 비용 기업을 억지로 양의 생산에 포함하지 않습니다.

차별화 수요는 `U=α(q1+q2)−β(q1²+q2²)/2−γq1q2+기타재화`, `p_i=α−βq_i−γq_j`에서 유도합니다. α=a, β=b, γ=ρβ이고 대칭 비용 c입니다. 직접수요 계수는 `A=α/(β+γ)`, `B=β/(β²−γ²)`, `D=γ/(β²−γ²)`입니다. 베르트랑 반응함수는 내부해에서 `(A+Dp_j+Bc)/(2B)`입니다. ρ=1은 수요행렬이 특이하므로 제외하고 동질재 모형에서 별도 취급합니다. 순차적 가격경쟁은 기업 1 가격 확약 후 기업 2 최적 대응으로, 이 대칭 대체재 모형의 후발자 이점을 확인합니다. 서로 다른 ρ의 후생 차이는 선호 변화도 포함하므로 순수 경쟁정책 효과가 아닙니다.

동질재 소비자잉여는 `bQ²/2`, 사중손실은 `b[(a−c)/b−Q]²/2`입니다. 차별화 제품 소비자잉여는 `β(q1²+q2²)/2+γq1q2`입니다. 총잉여는 소비자잉여+기업이윤 합계이고, 진입 탭에서만 `ne`를 차감합니다. HHI는 수량 점유율의 제곱합×10,000, 러너지수는 `(P−c)/P`이며 인위적인 기업 배분이 없는 완전경쟁 기준의 HHI는 표시하지 않습니다. 같은 HHI라도 전략변수에 따라 가격 마진은 다릅니다.

자유진입은 `π(n)−e≥0`, `π(n+1)−e<0`을 만족하는 정수 n이며, 순이윤 0에서도 진입하는 규칙입니다. 사회계획자는 기업 수만 선택하고 이후 쿠르노 경쟁을 유지합니다. `W(n)=(a−c)²/(2b)·[1−1/(n+1)²]−ne`를 0기업까지 포함해 최대화하고 후생 동률이면 더 적은 기업 수를 선택합니다. `(a−c)²/(be)>10¹²`인 극단적으로 작은 진입비용에는 정수 최적값을 표시하지 않습니다. 시장 규모·비용에 대한 조건부 이론 실험이며 실제 기업의 예측치가 아닙니다. 용량 제약·반복게임·내생적 품질 투자는 포함하지 않습니다.

### 저장과 검증

조건을 바꾸면 이전 결과와 CSV 저장을 비활성화합니다. 기업 2 비용은 해당 화면에서 적용해야 전체 CSV를 저장할 수 있습니다. CSV에는 입력 조건, 모형별·기업별 결과, 담합 이탈, 비용 비대칭 실험, 제품 차별화 조건과 결과, 기업 수 1~100 및 진입 분석, 저장한 비교 기준을 기록합니다. 저장 기준은 새 계산 중 유지되고 새로고침하면 지워집니다. 기존 전국표·지역표와 상태를 공유하지 않습니다.

`oligopoly-math.js`는 순수 계산, `oligopoly.js`는 화면, `oligopoly.css`는 스타일입니다. 기존 `app.js`와 `index.html`에 메뉴와 자산을 연결했습니다. `node oligopoly-check.cjs`는 강의 기본 예제, 3기업 예제, 비대칭·경계해, 선도자 이윤의 독립 탐색, 공통 수요·최적조건, 제품 독립성, 후발자 이점, 정수 진입·후생의 독립 탐색, 단위 배율, 입력 오류 및 브라우저 전역 초기화의 15개 검증 묶음을 실행합니다. 결과는 `oligopoly-verification.json`입니다. 강의 자료의 PDF 원문은 게시하지 않습니다.

## 15. 원가·마크업 가격결정 (2026-11-18)

**원가·마크업 가격결정** 메뉴에서 강의 1.8절의 예산원가·마크업 절차를 실습합니다. 자료를 불러오지 않아도 사용할 수 있는 독립적인 가상 기업 실험입니다. 산업연관표에서 기업의 비용·수요·마크업을 추정하지 않습니다. 기존 산업 간 가격 파급과 구분합니다. 강의 PDF 원문은 배포하지 않습니다.

### 예산원가와 가격

예산산출량 B, 단위 직접비 d, 기간 간접비 H, 직접원가 마크업 k, 총원가 이윤 마크업 r, 자본자산가치 V, 기간 목표수익률 TRR를 입력합니다. 직접비는 수량에 비례하고 간접비는 해당 기간 고정이라고 단순화합니다. 비용·수량·목표수익률은 같은 기간, 금액은 동일한 임의 통화입니다. 상단 표시 단위는 이 실험에 영향을 주지 않습니다.

- 평균직접비 ADCᵦ=d, 평균총원가 ATCᵦ=d+H/B.
- 직접원가 가격: P=d(1+k). k는 간접비 회수와 이윤을 모두 포함합니다.
- 총원가 가격: P=(d+H/B)(1+r). d>0이면 간접비 마크업 g=(H/B)/d를 사용한 d(1+g)(1+r)와 같습니다.
- 조정 마크업 가격: P=ATCᵦ(1+r+δ). δ는 %p 입력이며, 제품·경쟁자·소비자 계층 중 판단 근거를 기록합니다. 앱이 적정 조정폭을 추정하지 않습니다.
- 목표수익률 가격: P=ATCᵦ+TRR×V/B. 목표 마크업 t=TRR×V/(B×ATCᵦ).

원가 대비 마크업과 매출 대비 이익률을 구분합니다. 총원가 마크업 20%는 매출이익률 약 16.67%입니다. 이 지표를 한계비용 기준 러너지수로 읽지 않습니다. 예산량을 전부 판매할 때의 이윤·자본수익률을 비교하며, 직접원가 방식의 간접비 미회수 손실도 표시합니다. 비교 기준을 저장한 뒤 조건을 바꾸면 가격·예산이윤 차이를 확인합니다. 저장 기준은 새로고침 시 초기화됩니다.

### 가격 고정·판매량

예산가격 중 하나를 선택하고 실제 생산·판매량 q를 지정합니다. 생산=판매, 재고 없음, 단위 직접비 일정, 기간 간접비 고정을 가정합니다. 실제 수량을 바꿔도 설정 가격은 그대로 유지합니다.

```text
매출 = Pq
실제 비용 = dq + H
실제 이윤 = (P−d)q − H
실제 평균총원가 = d + H/q  (q>0)
실제 자본수익률 = 실제 이윤 / V  (V>0)
손익분기 수량 = H/(P−d)  (P>d)
```

차트는 고정가격 이윤과 목표이윤 TRR×V를 표시합니다. q=0이면 실제 평균원가·매출이익률, V=0이면 자본수익률을 정의할 수 없으므로 —로 표시합니다. 단위 공헌이익이 0 이하이면 양의 판매량으로 고정비를 회수하는 손익분기점을 제시하지 않습니다. 손익분기 수량은 연속값이며 정수 단위 판매 시 올림해야 합니다. 수요·생산능력·세금·금융비용은 포함하지 않습니다. 판매량은 외생적인 사용자 조건이고 이윤 극대화 결과가 아닙니다.

### 간접비 배부·ABC

두 제품 A·B의 예산수량, 단위 직접비, 제품별 총원가 마크업과 세 활동(생산준비·구매주문·품질검사)의 원가·동인 소비량을 입력합니다. 전통 방식은 제품 수량에 비례하여 총간접비를 배부합니다. ABC는 각 활동의 원가를 각 제품의 활동동인 비율로 배부합니다. 제품 단위는 비교 가능하다고 가정합니다.

```text
전통 배부액_j = 총간접비 × B_j / ΣB
활동 배부율_i = 활동원가_i / Σ제품 동인소비량_ij
ABC 배부액_j = Σ활동 (활동 배부율_i × 동인소비량_ij)
제품 가격_j = (직접비_j + 배부액_j/B_j) × (1+r_j)
```

강의 A 9,000개·B 1,000개, 생산준비비 100,000, 준비횟수 A 10회·B 40회가 초기값입니다. 직접비 50·80, 마크업 20%는 가격 비교를 위해 추가한 가상값임을 표시합니다. 전통 배부는 90,000·10,000, ABC는 20,000·80,000입니다. 원가합계와 배부합계를 대조하며 제품 간 이동은 총간접비를 바꾸지 않습니다. ABC의 적절성은 원가동인이 실제 자원 소비를 설명하는지에 달려 있습니다. 이 실험은 미사용 용량을 분리하는 TDABC를 구현하지 않습니다.

원가가 양수인데 동인 합계가 0인 활동은 거부합니다. 원가와 동인이 모두 0이면 배부액은 0, 배부율은 정의 불가로 표시합니다. 직접비 0일 때 활동별 간접비 마크업 비율은 정의되지 않지만 원가 합산으로 가격은 계산합니다. 실제 시장 수요나 판매가능 가격을 추정하지 않습니다.

### 저장·검증

예산·판매 실험 CSV에는 입력·가정·선택 가격방식·실제 손익·수량별 손익·저장 비교 기준을, ABC CSV에는 제품과 활동별 입력·배부액·가격·합계 검증을 기록합니다. 비율은 CSV에서 소수(0.2=20%)입니다. 예산 입력 변경 시 예산·손익 결과를, 실제 수량/선택 방식 변경 시 손익 결과를, ABC 입력 변경 시 ABC 결과를 지우고 관련 내보내기를 비활성화합니다. 세 실험의 상태는 전국·지역 산업연관표 상태와 독립적입니다.

`pricing-math.js`, `pricing.js`, `pricing.css`를 기존 파일과 같은 위치에 둡니다. 계산은 브라우저 JavaScript로 수행하고 서버·키·추가 패키지는 필요하지 않습니다. 행렬·파이썬 실습 및 퀴즈는 추가하지 않습니다.

`node pricing-check.cjs`로 예산가격·목표이윤, 마크업/이익률, 가격 고정, 판매 0·자산 0, 손익분기, 강의 ABC 예제, 다중 활동 배부, 원가 보존, 동인 단위 불변성, 부적합 입력, 브라우저 전역 초기화의 16개 검증 묶음을 실행합니다. 결과는 `pricing-verification.json`에 기록합니다.
