# 산업연관 LAB

산업연관표·투입산출표를 불러와 산업 구조와 최종수요 변화의 파급효과를 분석하는 교육용 웹앱입니다. 특정 연도나 분류에 고정되지 않습니다. 한국은행 2023년 네 분류는 사용법을 익히기 위한 예시 자료입니다.

## 1. 내 자료 분석

1. **내 자료 불러오기**에서 XLSX 또는 UTF-8 CSV를 선택합니다. 파일은 30MB 이하이며 브라우저 내부에서 처리됩니다.
2. 한국은행 총거래표·국산거래표·수입거래표 형식은 헤더 위치, 산업 코드, 총산출·부가가치 행, 연도·단위를 찾아 자동 연결합니다. 시트명 또는 구조가 다른 파일은 직접 설정합니다. 자동 인식 후에도 자료 설정에서 내용을 확인·수정할 수 있습니다.
3. **자료 구조 설정**에서 분석 시트, 거래금액/투입계수 구분, 총거래/국산 기준, 첫 거래값 셀, 산업 수를 지정합니다. 산업 수는 1~600개입니다.
4. 산업 코드·이름의 첫 셀을 지정하면 아래 방향으로 읽습니다. 생략하면 순번·코드를 사용합니다. 거래 블록의 행·열 산업 순서는 같아야 합니다.
5. 거래금액표에는 총산출 벡터가 필수입니다. 총산출의 첫 셀과 읽는 방향(오른쪽 또는 아래)을 지정합니다. 투입계수표는 총산출 없이도 계수와 시나리오를 분석할 수 있습니다.
6. 부가가치, 국산·수입 거래표, 기준 최종수요는 선택적으로 연결합니다. 부가가치 입력은 거래금액표에서 금액, 투입계수표에서 계수입니다. 추가 시트는 주표와 동일한 산업 순서·수·단위·금액/계수 유형이어야 합니다.
7. 연도, 기준가격, 출처와 금액 단위를 확인하고 **이 설정으로 분석하기**를 누릅니다. 연도 미상은 비워 두세요. 단위를 모르면 먼저 원자료 설명을 확인하세요.

인식되지 않은 파일도 원자료 탐색에서 모든 시트를 행·열 좌표로 볼 수 있습니다. 분석에 필요한 범위를 지정하기 전에는 파급효과 계산이 활성화되지 않습니다. 수식 셀은 Excel 등에서 계산 후 저장된 수치가 필요합니다. 거래 블록의 빈 셀은 자동으로 0으로 간주하지 않습니다.

**지원 모형의 범위:** 산업×산업 또는 상품×상품의 대칭 정방형 투입산출표입니다. 행과 열의 분류가 다른 공급·사용표는 이 앱에서 직접 투입산출 모형으로 계산할 수 없으며, 적절한 가정으로 대칭표를 먼저 작성해야 합니다. 모든 기관의 복잡한 Excel 배치를 자동으로 인식한다는 의미는 아닙니다.

### 입력 양식

`data/io-template.xlsx`는 교육용 가상 3산업 표이며 실제 통계가 아닙니다. 값을 내 자료로 바꿔 사용할 수 있습니다. 기본 설정은 첫 거래값 C2, 산업 수 3, 산업코드 A2, 산업명 B2, 총산출 F2 아래로, 부가가치 G2 아래로입니다. H2 아래로를 기준 최종수요로 지정할 수도 있습니다. 연도·출처·단위·총거래/국산 구분은 본인의 자료에 맞게 지정하세요.

`code,name,<산업코드들>,output,value_added` 형식의 첫 행은 범위를 제안합니다. 적용 전에 자료 기준과 단위를 직접 확인해야 합니다. 부가가치 자료가 없다면 해당 설정은 비워 두세요.

## 2. 유지된 분석 기능

- **산업 대시보드:** 총산출·부가가치·수입중간투입률, 산업명·코드 검색, 지표별 순위, 상위 중간투입·배분 연결. 자료가 없는 지표는 0 대신 ‘자료 없음’ 또는 ‘—’으로 표시합니다.
- **원자료 탐색:** 모든 시트의 행·열 선택, 항목 검색, 조회 결과 CSV. 인식된 통계표는 코드와 산업명을, 일반 표는 Excel 행·열 좌표와 셀값을 사용합니다.
- **파급효과 실험실:** 여러 산업의 수요 증가·감소, 금액 또는 최종수요 대비 변화율, 최초 수요와 추가 파급분, 산업별 전체 결과, 시나리오 비교, CSV 저장.
- **분석 가이드:** 방법·단위·해석 범위·출처·현재 자료의 검증 결과.

새 자료를 불러오거나 설정을 적용하면 수요 시나리오·심화 결과는 초기화됩니다. 분류 비교를 위해 저장한 A·B는 자료 전환 중에도 유지되며 새로고침하면 지워집니다. 모든 결과와 저장값은 현재 브라우저 메모리에만 유지됩니다. 원자료를 서버로 전송하거나 저장하지 않습니다. 새로고침 후에는 다시 파일을 열어야 합니다.

변화율 입력은 기준 최종수요를 연결했을 때만 사용할 수 있습니다. 한국은행 국산거래표에서는 수출·소비·고정자본형성·최종수요계를 자동 탐색합니다. 다른 표는 지정한 최종수요 벡터를 사용합니다. 기준액은 양수여야 하며 감소율은 -100% 이상입니다. 총산출이 제공된 경우 감소 후 생산액이 음수가 되는 입력은 거부합니다.

## 3. 단위와 출처

계산 내부 금액은 **업로드 원자료 단위**를 유지합니다. 원·천원·백만원·억원·십억원·조원은 표시 단위를 환산할 수 있습니다. `million USD` 등 다른 단위는 원래 단위 그대로 표시하며 환율 변환을 하지 않습니다. 계수(배)와 비율(%)은 금액 환산 대상이 아닙니다. 일반 원자료 격자는 셀의 단위를 단정하지 않고 ‘원자료값’으로 보여 줍니다.

CSV에는 실제 파일명·출처·연도·분류·산업 수·기준가격·원자료 단위·모형 기준을 기록합니다. 금액은 원자료 단위로 내보내며 없는 수입·부가가치 결과는 빈 값으로 남깁니다. 인식된 표라도 시트별 단위가 다르면 금액 환산 대상에서 제외합니다.

## 4. 계산 방법과 해석

행 i는 공급 산업, 열 j는 구매 산업입니다. x는 총산출, Z는 중간거래, v는 부가가치계수입니다.

```text
A = Z diag(x)^(-1)
L = (I - A)^(-1)
Δx = L Δf
추가 파급분 = (L - I) Δf
수입 자료 연결 시: Am = Zm diag(x)^(-1), Δm = Am L Δf
부가가치 연결 시: v = VA / x, Δv = diag(v) L Δf
```

- 국산거래표가 있으면 국산 A를 사용하여 국내 생산물 수요에 대한 파급효과를 계산합니다.
- 총거래표에 국산 또는 수입을 연결하면 차감으로 나머지를 구합니다. 세 표가 모두 있으면 `총거래 = 국산 + 수입`을 확인합니다.
- 국산·수입을 구분하지 못하는 총거래표는 **총거래 기반 산출 요구량**을 계산합니다. 이를 국내 생산유발액으로 해석할 수 없습니다. 화면과 CSV에 모형 기준을 표시합니다.
- 유발계수 시트가 없어도 거래표와 총산출 또는 직접 입력한 투입계수로 L을 계산합니다. 제공된 유발계수 시트는 원자료에서 탐색하고 계산 검증 패널에서 재계산값과 대조합니다.
- 총산출이 0이고 해당 중간투입 열과 부가가치도 0이면 투입계수를 0으로 처리하고 안내합니다. 총산출 0인데 투입이 존재하면 오류입니다.
- 역행렬 잔차 `max| (I−A)L−I | < 10^-8`과 수치 안정성을 확인합니다. 수입·부가가치 계수는 해당 자료가 있을 때만 계산합니다.
- 영향력계수 = L 열합 / 열합 평균. 감응도계수 = L 행합 / 행합 평균. 분류 내부의 상대 지수이며 투자수익성·정책 우선순위가 아닙니다.

기준자료의 가격·기술·투입비율이 고정된 선형 모형입니다. 가격 조정, 공급능력 제약, 기술 대체, 가계소득에 따른 추가 소비는 포함하지 않습니다. 결과는 조건부 추정이며 미래의 확정적 예측이 아닙니다. 생산유발액은 중간재의 반복 생산을 포함하므로 부가가치나 GDP 증가와 동일하지 않습니다. 최초 수요는 이미 총효과에 포함됩니다. 증가·감소가 섞이거나 감소만 있는 시나리오에는 순변화 대비 배율을 표시하지 않습니다.

서로 다른 연도·가격·분류·단위의 결과를 직접 비교하거나 계수를 임의 합산·평균하면 안 됩니다. 노동유발 분석은 현재 산업코드에 정확히 맞는 노동계수를 연결한 경우에만 제공합니다.

## 6. 실행과 GitHub Pages 제출

1. 배포 ZIP의 내용물을 GitHub 저장소 최상위에 올립니다. ZIP 자체나 감싼 폴더만 올리지 않습니다.
2. `index.html`, `style.css`, `app.js`, `advanced.js`, `comparison.js`, `worker.js`, `model.py`, `advanced.py`, `.nojekyll`, `README.md`, `data/`가 같은 최상위 위치에 있어야 합니다.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save를 선택합니다.
4. 실제 Pages 주소에서 파일 로딩·검색·계산·CSV 저장을 확인합니다. 과제의 제출 주소는 본인의 GitHub Pages 주소입니다.

별도 API 키나 Python 서버는 필요하지 않습니다. 브라우저 Web Worker에서 Pyodide 0.27.7, NumPy, openpyxl 3.1.5를 사용합니다. 최초 실행에는 외부 패키지 다운로드를 위한 인터넷 연결이 필요합니다. 로컬 점검은 정적 HTTP 서버를 사용하세요. `file://` 직접 열기는 지원하지 않습니다.

| 전·후방 연쇄 | 심화 분석 → 연쇄·산업구조, 점 선택·검색·사분면 필터 | L의 열합·행합을 각각 평균 1로 정규화. 분류 간 직접 비교 금지. |

| 가격 파급 | 심화 분석 → 가격 파급 | 국산 L과 피용자보수·순생산세·영업잉여 계수. 비용이 변하는 산업 또는 전산업 선택. |
| Ghosh | 심화 분석 → 공급충격 · Ghosh | 국산거래와 총산출. 기초투입 금액/비율 변화에 대한 조건부 산출가치 변화. |
| 산업구조 | 심화 분석 → 연쇄·산업구조 아래 표 | 수출률·수입률·부가가치율·중간투입률·국산화율·자기부문 중간투입 비중, 정의 툴팁. |
| 분류 비교 | 분류 비교·검증 → 분류 간 비교 | 예시 4분류 6개 조합 또는 사용자가 저장한 A·B. 같은 총수요를 세부산업 총산출 비중/균등으로 배분. |
| 취업·고용 | 심화 분석 → 취업·고용 | 현재 시나리오 또는 한 산업 수요 변화에 직접계수/공표 유발계수 적용. |
| 계산 검증 | 분류 비교·검증 → 계산 검증 | 역행렬 항등식, 제공 L/M/V, 항목별 유발액, 일치하는 예시 공표 통계 대조. |

각 분석은 CSV 저장을 제공합니다. 가격·노동·Ghosh CSV에 가정과 입력을 기록하고, 금액 결과는 원자료 단위로 내보냅니다. 입력이 바뀌면 이전 심화 결과를 지워 오래된 수치를 새 입력의 결과로 오해하지 않도록 합니다.

### 다른 연도·기관의 보조자료 연결

심화 분석 하단 **추가 자료 연결**에서 현재 파일의 시트·첫 수치 셀·방향을 지정합니다. 각 벡터는 현재 산업 수만큼, 유발계수는 N×N 정방형으로 읽습니다. **산업 순서·연도·통계 범위·단위를 먼저 맞춰야 합니다.** 가격 항목은 비용 금액 또는 산출 1단위당 계수로 지정합니다. 국산/수입 최종수요는 소비·고정투자·재고/귀중품·수출별로 연결할 수 있습니다. 없는 값은 0으로 채우지 않습니다.

노동계수는 별도의 UTF-8 CSV로도 연결할 수 있습니다:

```csv
code,jobs,employees,jobsMultiplier,employeesMultiplier
A,18.0,2.0,23.0,4.0
B,4.0,3.0,8.0,6.0
```

위 수치는 형식 설명용 가상값입니다. `jobs`=취업계수, `employees`=고용계수, `jobsMultiplier`/`employeesMultiplier`=공표 유발계수입니다. 모든 현재 산업코드가 정확히 한 번씩 있어야 합니다. 사용하지 않는 열은 삭제하거나 열 전체를 비우세요. 일부 산업에만 빈 값이 있는 계수 열은 거부합니다. 새 CSV는 이전 노동계수를 교체하며, 검증에 실패하면 이전 연결을 유지합니다. 원화 자료는 `명/10억원`, 외화 등은 `명/원자료 1단위`를 선택합니다. 잘못된 연도·단위의 계수를 가져오지 않도록 원자료를 확인하세요.

예시 보조자료는 통계표 18–20번의 2023년 대분류 33부문에 한해서 연결됩니다. 세부 분류에 33부문 계수를 복제하지 않습니다. 다른 분류·연도는 해당하는 노동계수를 연결하세요.

### 심화 공식과 해석

- **가격:** Δp = Lᵀ Δc. Δc는 각 비용항목의 산출 대비 계수×변화율 합입니다. 수입가격·투입량·노동생산성 고정, 비용 완전 전가를 가정합니다. 순생산세 변화율은 세율의 %p가 아닙니다. 음수인 순생산세·영업잉여에 양의 변화율을 적용하면 비용이 감소할 수 있습니다. 산출액 가중 평균은 CPI가 아닙니다.
- **Ghosh:** B = diag(x)⁻¹ Zᵈ, G=(I−B)⁻¹, Δx=GᵀΔq. q=x−Zᵈ의 열합은 부가가치+수입중간투입입니다. 고정 배분비율의 기초투입 변화 실험이며 물리적 공급능력 차질 예측으로 읽지 않습니다. 이 해석 문제는 Dietzenbacher (1997), https://onlinelibrary.wiley.com/doi/abs/10.1111/0022-4146.00073 을 참고합니다.
- **최종수요:** 국산 항목 f에 대해 생산 Lf, 부가가치 Vf, 수입 Mf+수입 최종수요를 사용합니다. 수입 최종수요가 연결되지 않으면 수입 중간재만 계산하고 표시합니다. 재고증감의 기여는 음수일 수 있으며 순합계가 0이면 기여율을 표시하지 않습니다. 보고서의 투자는 고정투자+재고/귀중품입니다.
- **노동:** 원자료가 백만원이고 e가 명/10억원이면 산업별 노동투입 = diag(e)LΔf/1,000. 직접투입 = eᵀΔf/1,000. 공표 유발계수 h는 총인원 hᵀΔf/1,000만 제공합니다. 공표 계수의 원래 계산·집계 방식에 따라 재계산한 33부문 eᵀL과 차이가 날 수 있으므로 오류 판정에서 제외합니다. 취업은 자영업자·무급가족종사자를 포함하며 고용은 임금근로자입니다. 모두 조건부 연간 노동투입 규모로 영구 신규채용 확정치가 아닙니다.
- **분류 비교:** 두 자료의 연도·가격·단위·모형이 같아야 합니다. A의 산업을 선택하고 동일한 수요 1단위를 B의 해당 세부 산업에 배분한 가중 승수와 비교합니다. 차이는 집계 수준과 수요 구성의 영향을 함께 담으므로 순수 집계편의만을 식별하는 추정치는 아닙니다. 메타데이터 미지정은 확인 체크가 필요합니다. 연결표는 `coarse_code,fine_code` 두 열로 모든 세부 산업을 한 번씩 연결합니다. 세부 총산출이 모두 0이면 산출 비중을 사용할 수 없습니다.

| 구조 지표 | 정의 |
|---|---|
| 수출률 | 수출액 / 총산출 ×100 |
| 수입률 | 수입계(수입생산물세 포함) / 총공급계 ×100 |
| 부가가치율 | 부가가치 / 총투입 ×100 |
| 중간투입률 | 국산+수입 중간투입 / 총투입 ×100 |
| 국산화율 | 국산 중간투입 / 전체 중간투입 ×100 |
| 자기부문 중간투입 비중 | 자기부문 중간투입 / 전체 중간투입 ×100, 앱에서 정의한 보조 지표 |

### 검증 자료의 범위

2023년 4개 분류 각각에서 역행렬·제공 유발계수·최종수요 유발액 16개 항목과 공표 통계 11개 항목을 대조합니다. 행렬은 최대 절대 오차 10⁻⁸, 금액표는 원자료 반올림과 규모, 공표 통계는 공표 자리수를 고려한 허용오차를 보여 줍니다. 보고서의 전산업 생산·부가가치·수입 유발계수는 **국산 최종수요 가중 평균**으로 계산합니다. 단순 산업평균이 아닙니다.

`advanced-verification.json`에 4분류 검증 결과와 작은 비대칭 가상표를 사용한 전치·행/열 분모·단위·누락자료·음수충격 점검 결과를 기록했습니다. 소스 저장소의 `tests/test_model.py`, `tests/test_advanced.py`, `tests/test_comparison.js`로 재현할 수 있습니다. `scripts/build_reference.py`는 공개 보조자료와 네 원본 Excel에서 화면용 비교 요약을 다시 만듭니다. `data/reference-2023.json`의 값은 현재 업로드에 임의 적용하지 않으며 연도·코드·총산출이 맞는 예시에만 연결합니다.
