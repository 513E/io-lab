산업구조 지표

열 제목에 마우스를 올리면 분자와 분모를 확인할 수 있습니다. 위 검색과 산업 선택이 함께 적용됩니다.

수입률(수입계/총공급)과 수입중간투입률(수입중간투입/총투입)은 다릅니다. 자기부문 중간투입 비중은 앱에서 분모를 명시한 지표입니다. 분모가 0이거나 자료가 없으면 —으로 표시합니다.

무엇이 산업의 생산을 유발했나요?

소비·고정투자·재고·수출의 기여를 확인합니다.

재고증감은 음수일 수 있어 기여율이 음수 또는 100% 초과가 될 수 있습니다. 순합계가 0이면 기여율을 표시하지 않습니다. 보도자료의 ‘투자’는 여기의 고정투자와 재고·귀중품을 합한 값입니다. 수입 분해의 최종재 포함 여부를 결과에 표시합니다.

비용 변화는 가격에 얼마나 전달되나요?

피용자보수·순생산세·영업잉여의 단위비용 변화 실험

Δp = Lᵀ Δc

국산 투입계수 사용 · 수입가격 고정 · 투입량과 노동생산성 고정 · 비용 완전 전가. 세율 %p 변화가 아닌 해당 비용의 % 변화입니다.

산업별 가격변화율은 합산하지 않습니다. 산출액 가중 평균은 CPI나 GDP 디플레이터가 아닙니다. 순생산세·영업잉여가 음수인 산업에서는 같은 양의 변화율이 비용을 더 낮출 수 있습니다.

기초투입 변화 실험 · Ghosh

거래표의 각 행을 총산출로 나누어 배분계수를 계산합니다.

B = diag(x)⁻¹ Zᵈ   ·   Δx = (I − B)⁻ᵀ Δq

배분비율을 고정한 기초투입 변화의 조건부 산출가치 실험입니다. 실제 생산 중단·공급능력 차질을 예측하는 모형이 아닙니다. 국산거래 기준 기초투입 q는 부가가치와 수입 중간투입의 합입니다.

수요 변화에 필요한 노동투입

취업은 전업환산 취업자, 고용은 임금근로자 기준입니다.

현재 분류와 일치하는 취업·고용계수를 연결하세요.

직접계수는 명/10억원 또는 명/원자료 1단위입니다. 10억원=1,000백만원입니다. 공표 유발계수는 집계 방식 때문에 현재 분류 재계산값과 다를 수 있습니다. 공표 열합만으로 수혜산업별 인원을 복원하지 않습니다. 결과는 연간 노동투입에 대응하는 조건부 규모이며 영구 신규채용 확정치가 아닙니다. 제공된 보조자료는 33부문에만 연결하며 세부 분류에 복제하지 않습니다.

추가 자료 연결 · 다른 연도·분류의 업로드 자료

자동 인식되지 않는 비용·최종수요·노동계수·유발계수는 현재 파일의 시트와 셀 범위를 연결하세요. 각 벡터·행렬의 산업 순서가 현재 분석 자료와 같아야 합니다.

code,jobs,employees,jobsMultiplier,employeesMultiplier · 열 전체가 비어 있으면 미입력으로 처리

노동계수 CSV는 위 단위 선택을 따릅니다. 사용하지 않는 계수 열은 삭제하세요. 현재 자료와 정확히 같은 코드·연도·분류를 사용해야 합니다.

분류 비교·계산 검증

같은 수요도 분류에 따라 달라지나요?

같은 집계 산업에 최종수요 1단위를 주고, 세부 산업에 배분한 결과와 비교합니다.

자료 불러오기에서 A를 분석한 뒤 A 저장, B를 분석한 뒤 B 저장을 누르세요. 두 저장값은 자료 전환 중에도 유지되며 새로고침 시 지워집니다.

A·B 저장 대기

역행렬은 단순 합산되지 않습니다. 차이는 집계 수준과 세부 수요 구성에 따른 것으로, 곧바로 계산 오류를 뜻하지 않습니다. 세부 계수의 단순 합계나 분류별 상대지수를 직접 비교하지 않습니다. 서로 다른 연도·단위·가격·모형 기준은 비교를 제한합니다.

계산 결과를 원자료와 대조합니다

항등식 검증과 제공된 계수·유발액 비교, 공표 통계 비교를 구분합니다.

제공된 L과 비교할 때 최대 차이가 난 산업코드를 표시합니다. 공표 통계는 반올림 정밀도에 맞춘 허용오차를 적용합니다. 전산업 유발계수는 국산 최종수요 가중값입니다. 2023 예시의 공표값은 일치하는 예시 자료에만 적용하며 사용자 업로드와 섞지 않습니다.

METHODS & SOURCES

분석 가이드

README 원문 ↗

01. 데이터부터 선택하세요

내 XLSX 또는 UTF-8 CSV를 열어 분석하세요. 한국은행 거래표 형식은 연도와 산업 수를 읽어 자동으로 연결합니다. 그 외 형식은 자료 설정에서 시트, 거래 범위, 총산출, 산업명과 단위를 지정하세요. 1~600개 산업을 지원하며 파일의 모든 시트를 탐색할 수 있습니다. 새로운 자료를 불러오거나 설정을 바꾸면 시나리오·심화 결과는 초기화됩니다. 분류 비교를 위해 저장한 A·B는 새로고침 전까지 유지됩니다. 네 가지 분류의 2023년 자료는 사용법을 익히는 예시입니다.

02. 단위와 지표를 구분하세요

금액 단위는 각 원자료를 따릅니다. 예시 자료의 단위는 백만원입니다. 1억원 = 100백만원, 1조원 = 1,000,000백만원입니다. 계수는 배, 비중은 %로 표시합니다. 국산거래 모형에서 생산유발계수 열합이 2.0이면 해당 산업의 국내 최종수요 1원 증가에 대해 전 산업 생산이 총 2원 유발되는 것으로 해석합니다.

Aᵈ = Zᵈ diag(x)⁻¹   ·   L = (I − Aᵈ)⁻¹
Δx = LΔf   ·   Δm = AᵐLΔf   ·   Δv = diag(v)LΔf

총생산유발액에는 최초 수요 Δf가 포함됩니다. 추가 파급분은 (L − I)Δf입니다. 파급효과 실험실의 수입유발액은 국내 생산에 필요한 수입 중간재 유발액입니다. 심화 분석의 최종수요 분해에서는 연결된 수입 최종재를 더하며 결과에 포함 범위를 표시합니다. 생산유발액은 부가가치나 GDP 증가액과 같지 않습니다.

03. 산업을 비교하세요

수입중간투입률 = 수입중간투입 ÷ 총투입 × 100. 영향력계수 = 생산유발계수의 해당 열합 ÷ 전 산업 열합 평균. 감응도계수 = 해당 행합 ÷ 전 산업 행합 평균. 두 연결성 지표는 분류 내 평균이 1인 상대 지수이며, 투자수익성이나 정책 우선순위를 직접 뜻하지 않습니다.

04. 해석의 범위를 지키세요

업로드한 자료의 기준연도·가격과 고정 투입계수를 사용합니다. 국산·수입을 구분할 수 없는 총거래표는 총거래 기반 산출 요구량을 계산하며, 이를 국내 생산유발액으로 해석하지 마세요. 수입·부가가치 자료가 없으면 해당 지표는 비워 둡니다. 산업×산업 대칭 정방형 표만 분석 모형에 연결할 수 있습니다. 수요 모형에는 가격 변화, 공급능력 제약, 기술 대체, 가계소득의 추가 소비 효과를 반영하지 않습니다. 별도의 가격 파급 모형은 수입가격 고정·완전 전가를 가정합니다. Ghosh는 고정 배분비율의 기초투입 변화 실험으로 실제 생산 중단의 예측과 구분합니다. 분류 간 유발계수는 단순 평균하거나 합산할 수 없습니다. 단위와 부문 구성이 다른 결과를 직접 비교하지 마세요. 감소 시나리오도 선형 모형의 가정 아래 계산합니다.
